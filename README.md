# Bootstrap 5 Sample Portfolio

A sample portfolio website created using **HTML5 and Bootstrap 5** for learning and practicing responsive web design and Bootstrap components.

## Technologies Used

* HTML5
* Bootstrap 5

## Features

* Responsive navigation bar
* About section
* Skills section
* Education section
* Projects section
* Contact form
* Responsive Bootstrap grid
* Bootstrap cards, buttons, progress bars, tables, and forms

## Disclaimer

This project is created for **learning and study purposes only**.

All names, personal details, contact information, education details, project information, and other content used in this sample portfolio are **dummy/sample data** and do not represent real individuals or actual information.

The projects and skills mentioned in this sample are included only for demonstration and practice purposes.
